# Inventory Management & RESTful API System

A full-featured Inventory and Sales Management System built using **Python** and **Django**, featuring both traditional Web UI (MVT) and a RESTful API architecture using **Django REST Framework (DRF)**.

## Key Features
- **Data Modeling & Schemas:** Designed relational models for Suppliers, Purchase Bills, Purchase Details, Sale Bills, and Sale Details.
- **RESTful API Development:** Built nested serializers and `ModelViewSet` routing for efficient data delivery.
- **Admin Customization:** Enhanced database query efficiency and customized the admin interface with Jazzmin.

## Tech Stack
- **Language:** Python
- **Framework:** Django & Django REST Framework
- **Database:** SQLite / PostgreSQL
- **Testing Tools:** Postman
